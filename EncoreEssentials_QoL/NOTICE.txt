Ideas, not code
  Leatrix Plus, Enhance QoL, Better Fishing and Angleur are All Rights Reserved.
  Encore-QoL takes feature ideas from them and is written on the WoW API with its
  own code. It reads their saved settings at runtime only to tell you when they
  already do something (and never changes them).
  The battleground data plan was worked out by reading how Capping (BigWigsMods,
  no licence) gets its data; no Capping code is used. Encore reads and answers
  Capping's addon messages so both addons share timers in a battleground.
  EzFishing Forever (MIT) inspired one-button fishing; no code is copied.
  HighGround (kemicofa, MIT) inspired the resurrection timer and the enemy bars
  (secure target and focus rows); no code is copied.
