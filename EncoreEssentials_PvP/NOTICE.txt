Ideas, not code
  The battleground data plan was worked out by reading how Capping (BigWigsMods,
  no licence) gets its data; no Capping code is used. Encore reads and answers
  Capping's addon messages so both addons share timers in a battleground.
  HighGround (kemicofa, MIT) inspired the resurrection timer and the enemy bars
  (secure target and focus rows); no code is copied.
